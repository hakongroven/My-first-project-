# ⚽ Triksing til jul 🎄

En enkel app for å registrere minutter med triksing fram til julaften.

## Funksjoner
- Nedtelling til julaften
- Registrer minutter (med hurtigknapper +5/+10/+15/+30), dato, rekord (flest triks på rad) og notat
- Fremdriftsring mot et mål (standard 1000 minutter, kan endres i innstillinger)
- Viser hvor mange minutter per dag som trengs for å nå målet før jul
- Dager på rad, søylediagram for de siste 14 dagene og merker å låse opp
- Sikkerhetskopi: last ned / hent inn data som JSON-fil

## Bruk
Alt ligger i `index.html` og dataene lagres lokalt i nettleseren på enheten (ingen innlogging, ingen server).

Enkleste måte å få den på mobilen: slå på **GitHub Pages** for repoet
(Settings → Pages → Deploy from branch → velg branchen og `/ (root)`),
åpne lenken på mobilen og velg **«Legg til på hjem-skjerm»**.

> Dataene ligger kun i nettleseren på den ene enheten. Bruk «Last ned kopi» innimellom
> hvis du vil være sikker på at ingenting blir borte.
